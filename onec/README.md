# Сторона 1С

Здесь живут инструкции по подключению тестовой базы и (на шаге 3) XML-исходники
нашего read-only CFE-расширения с доменными инструментами.

## Тестовая база (Windows-VM)

Что нужно на стороне VM, чтобы бэкенд дотянулся до базы через MCP-прокси:

1. 1С:Предприятие 8.3.20+.
2. Опубликованный на веб-сервере HTTP-сервис (на шаге 3 — `/hs/mcp/rpc`
   из форка `vladimir-kharin/1c_mcp`; до этого достаточно проверки связности).
3. Пользователь 1С с read-only профилем для агента (см. AGENTS.md, «Схема запросов»).
4. Сетевой доступ с VPS до VM по HTTP(S) — адрес вписать в `MCP_ONEC_URL` в `.env`.

Проверка связности с VPS:

```bash
curl http://<vm-host>/<base>/hs/mcp/health
```

На шаге 3 сюда лягут: форк `1c_mcp` (ядро MCP-протокола), наше расширение
с инструментами (`ДобавитьИнструменты`/`ВыполнитьИнструмент`, скилы `cfe-*`),
инструкция по установке CFE в тестовую базу.
