# Получение действующих договоров

Применяй этот паттерн, когда нужно получить действующие договоры:
- все действующие договоры;
- действующие договоры по конкретной организации;
- действующие договоры по нескольким организациям;
- действующие договоры по конкретному контрагенту;
- договор между конкретной организацией и конкретным контрагентом.

## Общие правила (обязательно)

1. Даты — ТОЛЬКО `ДАТА(ГГГГ,М,Д)` / `ДАТАВРЕМЯ(ГГГГ,М,Д,Ч,М,С)`. Строковые даты запрещены.
   Пустая дата (бессрочный договор) — `ДАТАВРЕМЯ(1,1,1,0,0,0)`.
2. Параметры `&` в `execute_select` НЕ поддерживаются — везде только литералы.
   «На дату» подставляй конкретное значение: если пользователь указал дату — её;
   если не указал — текущую дату (с точностью до конца дня: `ДАТАВРЕМЯ(ГГГГ,М,Д,23,59,59)`).
3. Сначала `validate_query` (тот же текст с `ПЕРВЫЕ 1`), потом полный `execute_select`.
   Без успешной проверки полный запрос не запускать.
4. Имена полей сверь через `get_metadata_structure` для справочника `ДоговорыКонтрагентов`
   (и `Контрагенты`, если фильтруешь по контрагенту) — реквизиты могут отличаться между базами.
5. Действительность договора определяется реквизитом `ВерсияДанных`. Его фактические значения
   в этой базе узнай запросом с `СГРУППИРОВАТЬ ПО ДоговорыКонтрагентов.ВерсияДанных`
   (перечисления строкой НЕ фильтруются) и подставляй нужный вариант литералом.
   Не выдумывай значение «Действует» до проверки.
6. Фильтр по контрагенту — ТОЛЬКО через подреквизит ссылки `ДоговорыКонтрагентов.Контрагент.ВерсияДанных`:
   - найди контрагента через `get_counterparty` (точное совпадение по `name`, не широкий поиск заново);
   - возьми из результата поле `ВерсияДанных` (например `"AAAAAQAAAGY="`);
   - подставь его литералом: `И ДоговорыКонтрагентов.Контрагент.ВерсияДанных = "AAAAAQAAAGY="`.
   Записи вида `ДоговорыКонтрагентов.Контрагент = <ссылка>` и
   `Справочник.Контрагенты.Ссылка("<УникальныйИдентификатор>")` в запросах НЕ использовать — они невалидны, запрос упадёт.
7. Один запрос чинить максимум 2 раза; третья ошибка подряд — остановись, покажи текст запроса
   и ошибку 1С пользователю и спроси уточнение.

## Все действующие договоры

    ВЫБРАТЬ РАЗРЕШЕННЫЕ ПЕРВЫЕ 1
        ДоговорыКонтрагентов.Ссылка КАК Договор,
        ДоговорыКонтрагентов.Номер КАК Номер,
        ДоговорыКонтрагентов.Контрагент КАК Контрагент,
        ДоговорыКонтрагентов.Организация КАК Организация,
        ДоговорыКонтрагентов.ДатаНачалаДействия КАК ДатаНачалаДействия,
        ДоговорыКонтрагентов.ДатаОкончанияДействия КАК ДатаОкончанияДействия
    ИЗ
        Справочник.ДоговорыКонтрагентов КАК ДоговорыКонтрагентов
    ГДЕ
        НЕ ДоговорыКонтрагентов.ПометкаУдаления
        И ДоговорыКонтрагентов.ВерсияДанных = <значение_из_группировки>
        И (ДоговорыКонтрагентов.ДатаНачалаДействия < ДАТАВРЕМЯ(2026,9,30,23,59,59)
            ИЛИ ДоговорыКонтрагентов.ДатаНачалаДействия = ДАТАВРЕМЯ(1,1,1,0,0,0))
        И (ДоговорыКонтрагентов.ДатаОкончанияДействия > ДАТАВРЕМЯ(2026,9,30,23,59,59)
            ИЛИ ДоговорыКонтрагентов.ДатаОкончанияДействия = ДАТАВРЕМЯ(1,1,1,0,0,0))

Пример:
- Вопрос: «покажи действующие договоры на 30.09.2026»
- Действия: (1) узнать значение `ВерсияДанных` через группировку; (2) заменить обе вхождения
  `ДАТАВРЕМЯ(2026,9,30,23,59,59)` на нужную дату → `validate_query` тем же текстом с `ПЕРВЫЕ 1`
  → `execute_select` без `ПЕРВЫЕ 1`.

Пример:
- Вопрос: «покажи действующие договоры на 30.09.2026 по организации ЭКСПРЕСС ОФИС»
- Действия: найти ИНН организации (запрос к справочнику, точное совпадение по названию — один поиск,
  дальше работай с результатом) → подставить ИНН литералом в `= "..."` → заменить дату →
  `validate_query` → `execute_select`.

## Действующие договоры по нескольким организациям (по ИНН)

То же, что «по организации», но последнее условие:

    И ДоговорыКонтрагентов.Организация.ИНН В ("7700000000", "5000000000")

Список ИНН — литералы в кавычках через запятую.

## Договор между организацией и контрагентом (пересечение условий)

Базовый запрос «все действующие договоры» + два условия:

    И ДоговорыКонтрагентов.Организация.ИНН = "7700000000"
    И ДоговорыКонтрагентов.Контрагент.ВерсияДанных = "AAAAAQAAAGY="

## Ошибки и «чего не делать»

- Не пиши `ГДЕ Статус = "Действует"` — перечисления строкой НЕ фильтруются; действительность
  определяй через реквизит `ВерсияДанных`, значение которого узнал через группировку.
- Не используй записи `ДоговорыКонтрагентов.Контрагент = <ссылка>` и
  `Справочник.Контрагенты.Ссылка("<УникальныйИдентификатор>")` — они невалидны, запрос упадёт;
  фильтр по контрагенту только через подреквизит ссылки `ДоговорыКонтрагентов.Контрагент.ВерсияДанных`,
  значение берётся из результата `get_counterparty`.
- Не используй параметры `&НаДату`, `&ОрганизацияИНН` и т.п. в `execute_select` — только литералы.
- Не выдумывай подполя ссылок (`Контрагент.ИНН`) без проверки структуры через `get_metadata_structure`.
- Если организация/контрагент не нашлись по точному названию — НЕ повторяй широкий поиск трижды;
  покажи пользователю найденные варианты и спроси уточнение.
