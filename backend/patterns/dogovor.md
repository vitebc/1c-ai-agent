# Запрос для получения действующих договор

Применяй этот навык когда нужно получить действующие договора;
- Все действующие договора
- По конкретному контрагенту
- По нескольким контрагентам
- Договор между контрагентом и организацией

## Все действующие договора

ВЫБРАТЬ РАЗРЕШЕННЫЕ ПЕРВЫЕ 1
	ДоговорыКонтрагентов.Ссылка КАК Договор,
	ДоговорыКонтрагентов.Контрагент КАК Контрагент
ИЗ
	Справочник.ДоговорыКонтрагентов КАК ДоговорыКонтрагентов
ГДЕ
	Не ДоговорыКонтрагентов.ПометкаУдаления
	И ДоговорыКонтрагентов.Статус = ЗНАЧЕНИЕ(перечисление.СтатусыДоговоровКонтрагентов.Действует)
	И (ДоговорыКонтрагентов.ДатаНачалаДействия < &НаДату
		ИЛИ ДоговорыКонтрагентов.ДатаНачалаДействия = ДАТАВРЕМЯ(1, 1, 1, 0, 0, 0))
	И (ДоговорыКонтрагентов.ДатаОкончанияДействия > &НаДату
		ИЛИ ДоговорыКонтрагентов.ДатаОкончанияДействия = ДАТАВРЕМЯ(1, 1, 1, 0, 0, 0))

Пример:
- Вопрос: «покажи действующие договора на 30.09.2026»
- Действия: заменить &НаДату на ДАТАВРЕМЯ(2006, 9, 30, 23, 59, 59) → `validate_query` → `execute_select` тем же текстом без `ПЕРВЫЕ 1`.
