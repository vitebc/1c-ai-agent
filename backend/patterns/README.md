# Папка паттернов чат-агента

Паттерн = файл `backend/patterns/<name>.md`. Ленивая подгрузка моделью
через инструмент `get_pattern({"name": "<name>"})` — в момент нужды,
а не в каждом запросе. Бэкенд перечитывает папку на каждый запрос.

```markdown
---
name: query-patterns
description: шаблоны запросов 1С — даты, фильтры, проверка
---

<текст: правила + примеры. Возвращается модели как tool result.>
```

Правила:

- `name` — латиница/цифры/`-`, обязан совпадать с именем файла без `.md`.
- `description` — одна строка, попадает в описание тулзы `get_pattern`.
- Тело после второго `---` — сам паттерн. Может быть любым markdown.
- Только плоский поднабор frontmatter (как у скилов/агентов, см. `app/frontmatter.py`).
- Битый файл не роняет чат: паттерн пропускается, причина — в логе
  (`patterns.errors`). Пустое имя в запросе — ошибка тулзы, а не падение.
- Имя в запросе валидируется (`^[a-z0-9-]+$`); чтение строго внутри папки.
