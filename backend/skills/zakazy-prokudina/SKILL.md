# Заказы клиента

Сценарий «покажи N последних ЗаказКлиента по контрагенту (+ фильтр по сумме)».

1. Контрагента ищи `get_counterparty` нечётко: разбей фразу на слова, ищи ПОДОБНО %слово%.
2. Заказы — `execute_select` по `Документ.ЗаказКлиента`, фильтр по найденному контрагенту/партнёру, сортировка по дате убывания, лимит под вопрос.
3. «Оставь», «убери», «покажи детали» — работа со строками прошлого ответа из истории, новый широкий поиск не начинай. Не хватает поля (сумма, статус) — добери одним точечным `execute_select` по номерам.

Пример:
- Вопрос: «покажи пять последних заказов Прокудина»
- Действия: `get_counterparty({"query": "Прокудин"})` → `execute_select` с фильтром по партнёру, `УПОРЯДОЧИТЬ ПО Дата УБЫВ`, лимит 5.
- Вопрос: «оставь с суммой больше 0»
- Действия: отфильтровать строки прошлого ответа; сумм нет — один `execute_select` по номерам из таблицы.
