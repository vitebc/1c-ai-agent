### I. Общие требования
1. **Отсутствие остатков в кассе (Зачет по организациям):**
   - *Источник:* Отчет «Ведомость по денежным средствам».
   - *Настройки:* Группировка (`Организация`, `Банковский счет/касса`), Отбор (`касса "Зачет"` по каждой Организации, `Сумма упр. учета (кон. ост.) != 0`), Период (`с даты последнего аудита по текущую дату`).
   - *Критерий:* `КЗ = количество организаций с ненулевыми остатками в кассе`.

2. **Денежные средства на закрытых расчетных счетах:**
   - *Источник:* Отчет «Ведомость по денежным средствам».
   - *Настройки:* Группировка (`Организация`, `Банковский счет/касса`), Отбор (`Вид денежных средств = Безналичные`, `Банковский счет / касса.Дата закрытия Заполнена`, `Сумма упр. учета (кон. ост.) != 0`), Период (`с даты последнего аудита по текущую дату`).
   - *Критерий:* `КЗ = количество организаций с ДС на закрытых р/с`.

3. **ДС на закрытых организациях:**
   - *Источник:* Отчет «Ведомость по денежным средствам».
   - *Настройки:* Группировка (`Организация`, `Банковский счет/касса`), Отбор (`Организация.Закрыта = Истина`, `Сумма упр. учета (кон. ост.) != 0`), Период (`с даты последнего аудита по текущую дату`).
   - *Критерий:* `КЗ = количество закрытых организаций с остатками в кассах и р/с`.

4. **Дублирование наименований касс:**
   - *Источник:* Справочник «Кассы» / «Банковские счета».
   - *Настройки:* Группировка (`Организация`, `Банковский счет/касса`), Отбор (`Период = Текущая дата`, поиск одинаковых Наименований в рамках одной Организации).
   - *Критерий:* `КЗ = Количество организаций с дублированием наименований касс`.

5. **Расхождения по суммам договоров займа:**
   - *Источник:* Внешний отчет С593 «Проверка суммы договора займа с сотрудником с суммой в РКО или ППИ».
   - *Настройки:* Отбор (`Период = с даты последнего аудита по текущую дату`).
   - *Критерий:* `КЗ = количество строк расхождений между договором и платежным документом (РКО, ППИ)`.

6. **Разнонаправленные остатки по займам физлица:**
   - *Источник:* Универсальный отчет «Погашение займов сотрудниками организаций».
   - *Настройки:* Группировка (`Физ. лицо`, `Договор займа`), Отбор (`Основной долг (кон. ост.) != 0`, `Период = Текущая дата`).
   - *Критерий:* `КЗ = количество физлиц, имеющих остатки по договорам займа с разными знаками (+ и -)`.

7. **Некорректные статьи затрат банковских документов:**
   - *Источник:* Отчет «Движения денежных средств».
   - *Настройки:* Период (`Текущий месяц`), Группировка строк (`Контрагент, подотчетник, касса ККМ (Иерархия)`, `Статья ДДС (Элементы)`, `Приход расход`, `Документ движения`).
   - *Отборы:* `Вид ДС = Безналичные`; `Статья ДДС В списке (70.1, 70.2, 70.3, 70.4, 70.5, 22.12, 58.2, 1.2)`; `Контрагент НЕ в группе (2 ФИЛИАЛЫ, 6 ПРОЧИЕ)` и НЕ является банком / получателем алиментов.
   - *Критерий:* `КЗ = количество выявленных документов-нарушителей`.

8. **Перекрестная задолженность подотчетника по разным организациям:**
   - *Источник:* Универсальный отчет «Взаиморасчеты с подотчетными лицами».
   - *Настройки:* Группировка (`Подотчетное лицо`, `Организация`).
   - *Критерий:* `КЗ = количество подотчетных лиц, у которых одновременно есть задолженность в разных организациях`.

9. **Ошибочные статьи расхода на приходных операциях:**
   - *Источник:* Отчет «Движения денежных средств».
   - *Настройки:* Период (`Текущий месяц`), Группировка (`Организация`, `Статья ДДС`), Отбор (`Приход расход = Приход`, при этом Статья ДДС имеет характер Расхода).
