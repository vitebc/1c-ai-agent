# Формат рантайм-скила чат-агента

Скил = папка `backend/skills/<name>/` с файлом `SKILL.md`. Новый сценарий —
новый файл, без кода и рестарта (бэкенд перечитывает папку на каждый запрос).

```markdown
---
name: zakazy-prokudina
description: последние заказы клиента, фильтр по сумме
tools: [get_counterparty, execute_select, validate_query]
---

<текст: системный промпт + 1-2 примера. Подставляется в конец базового.>
```

Правила:

- `name` — латиница/цифры/`-`, обязан совпадать с именем папки.
- `description` — одно-два предложения, по ним идёт авто-матчинг запроса (эмбеддинги).
- `tools` — подмножество имён из `ToolRegistry`. Неизвестные имена игнорируются с warning в лог.
- Тело после второго `---` — дополнение к системному промпту + примеры. Может быть пустым.
- Поддерживается только этот плоский поднабор frontmatter (без вложенностей и многострочников).
- Битый файл не роняет чат: скил пропускается, причина — в логе (`skills.errors`, см. `GET /skills`).
