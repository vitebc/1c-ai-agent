# Каталог отчётов

## sales_by_warehouse

Продажи по складам: номенклатура, склад, количество, сумма.
Периоды: квартал (ГГГГ-Q1..Q4), полугодие (ГГГГ-H1/H2), год (ГГГГ-Y).
Разбивки по дням и месяцам нет — минимальная детализация квартал.

## debtors

Дебиторская задолженность: контрагент, ИНН, сумма долга.
Периоды те же: квартал, полугодие, год. Показывает только должников
с ненулевым долгом.

## Как заказать отчёт

Назовите макет, период и фильтры (склад, лимит строк). Лимит — до 100 строк.
