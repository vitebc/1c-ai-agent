# Заведение нового контрагента

## Документы

Для заведения нужны: ИНН, карточка контрагента и подписанный договор.
Без договора — только черновик карточки, операции запрещены.

## Проверка

Перед заведением менеджер проверяет контрагента по ЕГРЮЛ:
статус действующий, адрес не массовый, директор не дисквалифицирован.

## Утверждение

Карточку заводит менеджер, утверждает руководитель отдела продаж.
Срок заведения — 1 рабочий день с получения всех документов.
