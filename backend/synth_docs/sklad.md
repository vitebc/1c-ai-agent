# Правила складского учёта

## Инвентаризация

Основной склад инвентаризируется каждого 1-го числа месяца.
Розничный склад инвентаризируется еженедельно, по понедельникам.

## Расхождения

Расхождение свыше 1 000 рублей — служебная записка на имя руководителя склада
в день обнаружения. Меньше 1 000 рублей — фиксируется в журнале расхождений.

## Приёмка

Приёмка товара — в день поставки, количество сверяется с накладной.
